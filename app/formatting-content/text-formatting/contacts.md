For contact details, you can either:

- use the [contact directory on your organisation page](/publish-update-retire-content/organisations-people/organisations/#contact-details) – you’ll be given a code you can copy and paste into the content
- create contact details within the content

Your organisation's most used contact details should be in the contact directory. If the details in the directory are updated, they'll automatically update in your content too.

If you want to create contact details within the content, use the code $C above and below the details.

For example:

```
$C
Department for Examples
< example@example.com >
Telephone: 08081 570 422
Monday to Friday, 8am to 6pm
Saturday, 9am to 1pm
[Find out about call charges](/call-charges)
$C
```

Looks like this:

$A
Department for Examples
<example@example.com>
Telephone: 08081 570 422
Monday to Friday, 8am to 6pm
Saturday, 9am to 1pm
[Find out about call charges](https://www.gov.uk/call-charges)
$A

For help with writing out phone numbers, read the [style guide entry on telephone numbers](/writing-to-gov-uk-standards/style-guides/a-to-z-style-guide/#telephone-numbers).
