Steps can be used to explain a series of tasks to a user. 

Put each step on a separate line and number them, with 's' before each number. For example: 

``` 
s1. Write the content out. 
s2. Upload it to the website. 
s3. Check it has uploaded correctly. 
``` 

If there’s a heading following the steps, add one empty line space between the final step and the heading.
