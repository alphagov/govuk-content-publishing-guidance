Only use bold text to indicate interface elements that are explicitly telling the user what to do. For example:

1. Select **Start**.
2. Enter your information then select **Done**.

Do not use bold in other situations, for example to emphasise text. Read the [style guide entry on bold](/writing-to-gov-uk-standards/style-guides/a-to-z-style-guide/#bold) for more guidance.

To make bold text, add two asterisks either side of the text. For example:

``` 
Select **Start**.
```
