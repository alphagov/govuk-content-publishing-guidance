Statistic headlines highlight important numbers in content. 

The statistic and description must make sense when read aloud. 

To create a statistic headline, add ‘{stat-headline}’ above the headline and ‘{/stat-headline}’ below it. Add asterisks either side of the statistic. For example:

``` 
{stat-headline}  
*13.8 billion* years since the Big Bang  
{/stat-headline} 
``` 

You can only add statistic headlines to HTML attachments and manuals.
