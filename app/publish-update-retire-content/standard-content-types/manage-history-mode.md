History mode is automatically applied to certain standard content types when there’s a change in government. 

You’ll see a banner across the page explaining the content was published under a previous government. 

## Making changes to content in history mode 

If your content is in history mode, you can only update it if you have ‘managing editor’ permissions in Whitehall Publisher. 

If you need managing editor permissions, talk to one of your organisation admins.

Managing editors can either: 

- update the content without removing it from history mode 
- remove the content from history mode, so anyone can make changes to it 

When making changes, consider if you’ll need to [write change notes](/writing-to-gov-uk-standards/writing-guidelines/change-notes/) to let users know what you’ve done.

### Decide how to make changes 

Update the content but keep it in history mode if you’re:

- fixing a broken link or typo
- adding official document details
- making an update for security or data protection reasons
- withdrawing or unpublishing the content, if it meets the [criteria for when to withdraw or unpublish content](/writing-to-gov-uk-standards/plan-manage-content/retire-content/)

Remove the content from history mode if:

- you’re adding a response to a consultation or call for evidence
- you want to update a policy paper that’s still current government policy – you'll need to remove any political content (like ministerial forewords) and untag ministers from previous governments
- you want to update content that does not currently meet the criteria for [when history mode gets applied](/writing-to-gov-uk-standards/plan-manage-content/retire-content/#when-history-mode-gets-applied) – it might have met the criteria when it was first published or someone mistakenly ticked the ‘political’ box

If you cannot update content or remove it from history mode, you’ll have to publish a new edition of the content.

>[!NOTE]
>You can [get content advice](/accounts-support/get-content-advice/get-help-advice/) if you’re not sure about the right approach.

### Update content but keep it in history mode

Managing editors can update the content as normal, but they must not untick the box under the ‘Political’ heading.

Be aware that only other managing editors can make further changes and publish the draft.

### Remove content from history mode

Managing editors need to create a new draft and untick the box under the ‘Political’ heading before they save. The draft is now out of history mode and anyone can edit it.

Once the draft is published, the history mode banner will be removed and anyone can create new drafts from now on.

### If you cannot update content or remove it from history mode

There are some common solutions if you need to publish a changed version of the content:

- choosing a more appropriate [content type](/publish-update-retire-content/choose-content-type/) that should not go into history mode, like a detailed guide – you’ll need to publish a new version and then unpublish and redirect the old version before you make your changes
- if it’s a publication, choosing a more appropriate [publication type](/publish-update-retire-content/standard-content-types/publications/#choose-the-right-type-of-publication) that should not go into history mode, like a guidance publication – you can remove it from history mode and then publish a new draft with the updated publication type
- publishing a new version of the content and then withdrawing and potentially renaming the old version, so users will see where to find the current content

If you just want to add new attachments to an existing page, consider creating a [document collection](/publish-update-retire-content/standard-content-types/document-collections/). You can then publish the new attachments on separate pages and add them to the collection alongside the old content. You may want to rename the old content too.

## Putting content into history mode

Managing editors can put content from previous governments into history mode if it meets the criteria for [when history mode gets applied](/writing-to-gov-uk-standards/plan-manage-content/retire-content/#when-history-mode-gets-applied) but it was removed from history mode before.

They need to create a new draft and tick the box under the ‘Political’ heading before they save.

The draft is now in history mode, and only managing editors can make further changes and publish the draft.

## Updating the ‘associated government’

If the wrong government is appearing in the history mode banner, you’ll need to ask the Government Digital Service (GDS) to make that change.

Use the [content help form](https://support.publishing.service.gov.uk/content_advice/content_design_help_request/new) to make your request. You’ll need a Signon account with ‘content requesters’ permissions to access the form.
